PHASE 3: STK PUSH & B2C PAYMENT ENDPOINTS ✓
================================================================================

Files Modified:
  • api.php (added authenticated M-Pesa payment/disbursement endpoints)
  • utils/api.ts (added M-Pesa API methods)

Authenticated Endpoints Added:
  • POST /api/admin/mpesa/payment
    - Initiates STK Push to borrower
    - Validates loan status (must be 'active')
    - Calls Daraja API with correct timestamp-based password
    - Records transaction with checkout_request_id

  • POST /api/admin/mpesa/disburse
    - Initiates B2C disbursement to borrower
    - Validates loan status (must be 'approved')
    - Marks loan as 'active' upon initiation
    - Records transaction with command_id

  • GET /api/admin/mpesa/transactions
    - Retrieves M-Pesa transaction history
    - Optional filter by loan_id
    - Returns status, response codes, timestamps

API Helper Methods Added (utils/api.ts):
  • adminApi.mpesaInitiatePayment()
  • adminApi.mpesaInitiateDisbursement()
  • adminApi.mpesaGetTransactions()
  • adminApi.post()
  • adminApi.get()

Workflow:
  1. Admin calls /admin/mpesa/payment → Daraja OAuth token obtained
  2. Token cached to avoid rate limits
  3. STK Push API called with phone, amount, callback URL
  4. Transaction logged with 'stk_initiated' status
  5. Safaricom calls back to /mpesa/stk/callback
  6. Callback handler creates repayment if successful

Status: Ready for Daraja API calls

DATABASE SCHEMA
================================================================================

Table: mpesa_transactions
  Columns:
    id                     INTEGER PRIMARY KEY AUTO_INCREMENT
    loan_id                INTEGER (FOREIGN KEY → loans)
    transaction_type       VARCHAR(50) - c2b_validation, c2b_confirmation, c2b_timeout, 
                                        stk_initiated, stk_callback, b2c_initiated, 
                                        b2c_result, b2c_timeout
    phone                  TEXT - Customer's M-Pesa phone number
    amount                 REAL - Transaction amount
    mpesa_reference        TEXT - Unique receipt/reference from M-Pesa
    safaricom_receipt      TEXT UNIQUE - Safaricom receipt number (prevents duplicates)
    checkout_request_id    TEXT UNIQUE - STK Push identifier
    command_id             TEXT UNIQUE - B2C command identifier
    status                 VARCHAR(50) - pending, confirmed, completed, failed, timeout, 
                                        validation_result, stk_initiated, disbursed, etc.
    validation_result      VARCHAR(100) - accepted/rejected (C2B only)
    response_code          TEXT - Safaricom response code (for failures)
    response_message       TEXT - Safaricom response description
    request_payload        TEXT - Raw XML request (first 1000 chars)
    response_payload       TEXT - Raw XML response (first 1000 chars)
    created_at             TIMESTAMP
    updated_at             TIMESTAMP (auto-update)
