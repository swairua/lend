CRITICAL ISSUE FOUND: Foreign Key Mismatch in loans.borrower_id
==============================================================

THE PROBLEM:
-----------
Your database schema defines:
  loans.borrower_id -> users.id (directly)

BUT your application code expects:
  loans.borrower_id -> borrowers.id (intermediate table)

PROOF FROM CODE:
---------------

In routes/borrower.php:
  $borrower = one("SELECT id FROM borrowers WHERE user_id = ?", [$user['id']]);
  $bid = $borrower['id'];  // Gets borrowers.id
  INSERT INTO loans (borrower_id, ...) VALUES (?, ...)  // Stores $bid

In routes/admin.php (lines 56-57, 103, 143):
  LEFT JOIN borrowers b ON l.borrower_id = b.id        // Joins to borrowers.id
  LEFT JOIN users u ON b.user_id = u.id               // Then to users.id

In routes/admin.php (lines 190, 224, 252):
  $borrower = one("SELECT user_id FROM borrowers WHERE id = ?", [$loan['borrower_id']]);
                                                          ↑
                                        Treats as borrowers.id
